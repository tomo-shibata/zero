# プルリクエスト作成スキル

プルリクエストを作成するためのスキル。

## 事前に

- PR作成前に、`docs/rules/ai-review.md` に従い **AI相互レビューを別セッションのAIで1回** 済ませておくこと。
- 対象パスに一致するルールに違反していないか確認する。

## コミットメッセージ

- **Conventional Commits** 形式で書く。
  - 例: `feat: 取引の月次集計を追加`, `fix: 金額丸めの誤りを修正`, `refactor:`, `test:`, `docs:`, `chore:` など。

- コミットメッセージの末尾に次を付ける:

  ```

  ```

## PR本文の構成

**レビュアーが上から読めば理解できる順番**で、次の見出しで書く。

### 課題
- 何を解決するPRか。

### 背景
- 対応するイシュー。
- プラン。

### 解決策
- どう変えたか。
- 設計判断とトレードオフを **1〜2行** で。

### テスト
- 追加・変更したテスト。
- 手元での実行結果。

### レビュー観点
- 特に見てほしい箇所。
- 影響範囲。
- 未対応事項。

## 本文末尾

PR本文の最後に次を付ける:

```
🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

## 注意

- デフォルトブランチ上にいる場合は、先にブランチを切ってから作業する。
- GitHub操作には `gh` CLI を使う。
