# バックエンド アーキテクチャルール

`backend/internal/**` を読む・変更する・レビューするときに、先に読むこと。
関連: [開発ルール全体](../../../エージェント向けREADME.md)、[テストルール](../test/architecture.md)。

## 1. 単一責任の原則（SRP）を守る

- **1ファイル＝1つの責務**とする。
- **判定基準**: そのファイルがやっていることを **一文で言えること**。
  - ✅ 合格例: 「請求書の金額を計算する」
  - ❌ 不合格例: 「請求書周りの処理をいろいろやる」
- ファイルが大きくなってきたら、**責務の境界で分割する**。
